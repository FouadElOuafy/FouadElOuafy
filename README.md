## ⭐ Spotlight project

### 🎓 [Decentralized Academic Certificate Verification](https://github.com/FouadElOuafy/certificate-verification)

Tamper-proof diplomas on the blockchain. An issuer registers a salted SHA-256 hash of a certificate PDF on a smart contract, the student shares a QR code, and a recruiter verifies the document in seconds, without a wallet and without exposing personal data.
